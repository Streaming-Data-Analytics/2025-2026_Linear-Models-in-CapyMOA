## Project Overview
This project focuses on extending **CapyMOA** by integrating additional **linear models** from the **River** library.  
The goal is to bridge the gap between River (Python) and CapyMOA (Java + Python wrapper), enabling a consistent experimental comparison across frameworks.

The student will implement wrappers for selected River models inside MOA (Java), expose them in CapyMOA, and evaluate their behavior in streaming scenarios.

## Background
**River** is a Python library for online machine learning, offering a wide range of incremental models, including several efficient linear methods.

**MOA (Massive Online Analysis)** is a Java-based framework for data stream mining, which CapyMOA builds upon by providing a Python interface.

Currently, some models available in River are not present in CapyMOA. This limits the ability to:
- fairly compare models across frameworks,
- reuse well-established River implementations,
- benchmark CapyMOA against state-of-the-art online methods.

This project aims to reduce this gap by porting selected linear models into the CapyMOA ecosystem.

## Goals and Objectives
The project is divided into four main parts:

### 1. Model Integration (Core Task)
Select and implement a subset of the following River models:

- Logistic Regression
- Linear Regression
- Softmax Regression

The implementation must follow this pipeline:

- Re-implement (or adapt) the model in **Java (MOA)**
- Ensure compatibility with MOA streaming interfaces
- Wrap the Java implementation in **CapyMOA (Python)**
- Make the model usable within CapyMOA pipelines (e.g., prequential evaluation)

### 2. Cross-Framework Comparison
Evaluate the implemented models in both River and CapyMOA. The comparison must be performed on state-of-the-art dataset and must include:

- Predictive performance (e.g., accuracy, F1, etc.)
- Consistency between implementations
- Discussion of any discrepancies

### 3. Computational Performance Analysis
Compare execution efficiency between River and CapyMOA:

- Training and Inference time
- Memory usage

### 4. Integration in CapyMOA Tutorials
Reproduce and extend selected tutorials from https://capymoa.org/tutorials.html.

Requirements:
- Run at least 2 tutorials
- Include the newly implemented model(s) in the comparison
- Analyze how the new models behave compared to existing CapyMOA learners

## Datasets
The student should use a mix of:

- Standard streaming datasets: Electricity, CovType, etc.
- Synthetic dataset generated by hand

All datasets must be processed in a prequential setting.
