# Instructions to Run the Project

This document provides step-by-step instructions to set up the environment, build the custom Java files for MOA, and execute the experiments inside the Jupyter notebooks.

## Prerequisites

Before starting, ensure you have the following installed on your system:
- **Java Development Kit (JDK)** (JDK 11 or higher is recommended)
- **Python** (3.8 or higher)
- **Maven** (for building the custom MOA Java codebase)

## Project Structure

Here is an overview of the main folders and files in this repository:

```
2025-2026_Linear-Models-in-CapyMOA/
├── INSTRUCTIONS.md
├── README.md
├── requirements.txt
├── capymoa/
│   ├── notebooks/               # Tutorial notebooks for CapyMOA
│   └── src/capymoa/classifier/  # CapyMOA Python wrappers for the linear models
├── capymoa_vs_river/            # Jupyter notebooks for cross-framework comparison and performance analysis
└── deliverables/                # Project presentation
└── moa/
    └── moa/src/main/java/moa/classifiers/ # Custom MOA Java implementations (Logistic & Softmax Regression)
```

## Step 1: Build the Custom MOA Project

This project extends the standard MOA models. You first need to compile the custom Java code using Maven.

1. Clone the MOA repository:
   ```bash
   git clone https://github.com/Waikato/moa.git
   ```

2. Add the custom models into `/moa/src/main/java/moa/classifiers` folder of the MOA repository:
   ```bash
   cp moa/moa/src/main/java/moa/classifiers/LogisticRegression.java <MOA_REPOSITORY_FOLDER>/moa/src/main/java/moa/classifiers
   ```
   ```bash
   cp moa/moa/src/main/java/moa/classifiers/SoftmaxRegression.java <MOA_REPOSITORY_FOLDER>/moa/src/main/java/moa/classifiers
   ```

2. Build the project using Maven from the root directory of the MOA repository you have cloned:
   ```bash
   mvn clean package -DskipTests
   ```
   This will compile the Java source files (like `LogisticRegression.java` and `SoftmaxRegression.java`) and package them along with all the other classes of the library.

3. Create the `custom_moa_full.jar` required by the notebooks. Copy the built jar from the `target` directory of the MOA repository into the root of the project repository:
   ```bash
   cp <MOA_REPOSITORY_FOLDER>/moa/target/<YOUR_BUILT_MOA_JAR>.jar custom_moa_full.jar
   ```
   *(Note: Replace `<YOUR_BUILT_MOA_JAR>` with the actual name generated by Maven, e.g., `moa-202X.jar` depending on your pom.xml).*

## Step 2: Set Up the Python Virtual Environment

It is recommended to use a virtual environment to manage dependencies. Go back to the root of the repository and run:

1. Create a virtual environment named `.venv`:
   ```bash
   python -m venv .venv
   ```
2. Activate the virtual environment:
   - On **macOS/Linux**:
     ```bash
     source .venv/bin/activate
     ```
   - On **Windows**:
     ```bash
     .venv\Scripts\activate
     ```

## Step 3: Install Python Dependencies

With the virtual environment activated, install the required Python packages defined in `requirements.txt`:

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

This will install packages like `capymoa`, `river`, `scikit-learn`, `pandas`, `jupyter`, etc.

## Step 4: Run the Jupyter Notebooks

Now that the Java backend is built and the Python environment is set up, you can run the experiments comparing CapyMOA and River.

1. Start the Jupyter server from the root of the project:
   ```bash
   jupyter notebook
   ```
2. In the browser that opens, you can navigate to the respective folders and run the notebooks:

   **CapyMOA vs River Comparisons:**
   - `capymoa_vs_river/log_reg_cross_framework_comparison.ipynb`
   - `capymoa_vs_river/log_reg_computational_performance_analysis.ipynb`
   - `capymoa_vs_river/softmax_reg_cross_framework_comparison.ipynb`
   - `capymoa_vs_river/softmax_reg_computational_performance_analysis.ipynb`

   **CapyMOA Tutorials (Extended):**
   - `capymoa/notebooks/00_getting_started.ipynb`
   - `capymoa/notebooks/01_evaluation.ipynb`
